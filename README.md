# Simple Networking


*This is an outline of a simple implementation to connect remote machines with a TCP or a UDP connection (UDP hasn't really been set up though)*

**The code works on all three systems (Linux, MacOS, and Windows). There will be more code added soon though.**

This program works well, but to run it, OpenSSL will need to be installed on the system. The CMakeLists.txt file works well on unix systems.

***Note**
The secure connection has been tested and it works great. To run the secure connection, be sure to be situated in the build directory and execute the file in the objects directory with the appropriate command. Again this is for the secure tcp client/server programs.
